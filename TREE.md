## Dependency direction

`core` <- `model` <- `services` <- `jobs` <- `routers` / `mcp_server` <- `main` / `evals`, with `models.py` beside `core`. A layer imports only the layers to its left (the dashboard imports `jobs/nightly.py` to run it on demand). Keep it so: no `services` module imports a router.

## Where to make a change

- New HTTP endpoint: a router in `app/routers/`, included in `app/main.py`.
- New MCP tool: `app/mcp_server.py` (protocol) + `app/services/replies.py` (logic).
- Schema change: `app/models.py`, then `alembic revision --autogenerate`.
- New identifier or enum value: `app/core/vocab.py`.
- New text: `locales/en.json` (and `fr.json`).
- New page: a template in `app/templates/`, rendered with `i18n.TEMPLATES`.
- New setting: `app/core/config.py` + `.env.example` + `docker-compose.yml`.
